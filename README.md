# klimper. · Spielerisch Keyboard lernen

Eine interaktive Keyboard-Lernplattform für Kinder und Einsteiger:

- 16 geführte Lektionen in 4 Lernwelten (weiße Tasten, Lieder, schwarze Tasten, Akkorde)
- Interaktives Piano mit Web-Audio-Klang (5 Instrumente, Metronom)
- Notenlinien-Visualisierung (deutsche Notation & Solfege)
- Mikrofon-Tonerkennung zum freien Spielen
- Wissens-Quiz, Erfolge, Urkunde und Fortschrittsverfolgung

## Live-Version

**https://adrgrie-lgtm.github.io/Keyboard-/**

## Lokal starten

```bash
npm install
npm run dev
```

Die App läuft dann unter http://localhost:3000.

## Technologie

React 19 · TypeScript · Vite · Tailwind CSS 4 · Web Audio API
